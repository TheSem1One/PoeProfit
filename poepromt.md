# PoE 1 Profit Calculator — HTML Application

Створи повноцінний, сучасний та зручний калькулятор витрат і прибутку для Path of Exile 1.

## 1. Технічні вимоги

- Увесь застосунок має бути в одному файлі `index.html`.
- Використовуй чисті HTML, CSS та JavaScript.
- Не використовуй React, Vue, Angular або інші фреймворки.
- Не використовуй backend або базу даних.
- Для збереження даних використовуй `localStorage`.
- Застосунок повинен працювати локально, без сервера та інтернету.
- Після перезавантаження сторінки всі дані мають автоматично відновлюватися.

## 2. Основний функціонал

Зроби три основні секції.

### A. Expenses — Витрати

Таблиця з можливістю додавати та видаляти предмети.

Колонки:
- Item Name — назва предмета.
- Quantity — кількість.
- Price per Item — ціна одного предмета.
- Total — загальна вартість.

Формула:

`Total = Quantity * Price per Item`

Наприклад:

| Item | Quantity | Price | Total |
|---|---:|---:|---:|
| Scarab of Divinity | 10 | 5 | 50 |
| Map | 5 | 10 | 50 |
| Fragment | 3 | 15 | 45 |

Внизу автоматично показувати Total Expenses.

### B. Profit — Прибуток

Окрема таблиця з аналогічною структурою.

Колонки:
- Item Name
- Quantity
- Price per Item
- Total

Формула:

`Total = Quantity * Price per Item`

Наприклад:

| Item | Quantity | Price | Total |
|---|---:|---:|---:|
| Divine Orb | 2 | 150 | 300 |
| Chaos Orb | 50 | 1 | 50 |

Внизу автоматично показувати Total Profit.

### C. Summary — Підсумок

Окрема помітна панель, яка автоматично відображає:

- Total Expenses
- Total Profit
- Net Profit
- ROI (%)
- Status: PROFIT / LOSS

Формули:

`Net Profit = Total Profit - Total Expenses`

`ROI = (Net Profit / Total Expenses) * 100`

Якщо Net Profit більше 0 — показувати зелений колір.

Якщо Net Profit менше 0 — показувати червоний колір.

Якщо дорівнює 0 — показувати нейтральний колір.

## 3. Збереження даних

Це одна з найважливіших вимог.

Реалізуй збереження через `localStorage`.

Необхідно:
- Автоматично зберігати зміни після кожного введення.
- Зберігати всі предмети у витратах.
- Зберігати всі предмети у прибутку.
- Зберігати кількість та ціни.
- Відновлювати дані після перезавантаження сторінки.
- Не втрачати інформацію після закриття браузера.
- Зберігати дані навіть після закриття вкладки.

Використовуй окремий ключ, наприклад:

`poe1-profit-calculator-data`

Додай повідомлення `Saved`, коли зміни успішно збережені.

## 4. Додаткові можливості

- Кнопка Add Item для додавання нового рядка.
- Кнопка Delete для видалення предмета.
- Кнопка Clear All для очищення всіх даних з підтвердженням.
- Кнопка Export JSON для резервного копіювання даних.
- Кнопка Import JSON для відновлення резервної копії.
- Автоматичне оновлення всіх підсумків після кожної зміни.
- Можливість вводити десяткові значення цін.
- Якщо таблиця порожня — показувати зрозуміле повідомлення.

## 5. Дизайн

Зроби дизайн у стилі Path of Exile 1:

- Темна готична тема.
- Темно-сірий та чорний фон.
- Золотисті акценти.
- Стиль, який нагадує інтерфейс PoE.
- Акуратні таблиці.
- Читабельні шрифти.
- Приємні hover-ефекти.
- Адаптивний дизайн для різних розмірів екрана.

Не потрібно копіювати офіційний інтерфейс гри. Створи власний дизайн, натхненний атмосферою PoE.

## 6. UX

- Усі розрахунки повинні відбуватися миттєво.
- Не перезавантажувати сторінку після додавання предмета.
- Під час редагування ціни автоматично оновлювати загальну суму.
- Не допускати NaN та некоректних розрахунків.
- Порожні поля кількості та ціни трактувати як 0.
- Перед очищенням даних запитувати підтвердження.

## 7. Результат

Надай повний готовий код одного файлу `index.html`.

Не розділяй код на декілька файлів.

Не використовуй псевдокод або пропуски.

Застосунок повинен бути повністю робочим одразу після збереження файлу та відкриття його у браузері.

Особливо перевір:
1. Додавання предметів.
2. Видалення предметів.
3. Автоматичні розрахунки.
4. Збереження через localStorage.
5. Відновлення даних після перезавантаження сторінки.
6. Імпорт та експорт JSON.
